The one line a smart fridge would text its owner at 3am: a small appliance voice, awake all night, keeping count of the owner's late-night visits — and noting that even the pickles have started paying rent.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (1–140 characters, one line).
